# 자동 스크롤 리더 (Auto Scroll Reader)

소설·웹툰·문서를 손대지 않고 **원하는 속도로 천천히 자동 스크롤**해서 읽기 위한
안드로이드 앱입니다. 접근성 서비스로 동작하므로 네이버 시리즈, 카카오페이지,
브라우저의 웹소설 등 **어떤 앱 위에서든** 사용할 수 있습니다.

## 동작 방식

- 화면 위에 작은 조작 패널(시작/정지, 속도 슬라이더, 방향, 불규칙)을 띄웁니다.
- 아래에 열려 있는 앱에 **스와이프 제스처만** 보내 스크롤합니다.
  (대상 앱의 내용을 읽거나 조작하지 않습니다. 사람이 손가락으로 미는 동작만 자동화.)
- `SYSTEM_ALERT_WINDOW`(다른 앱 위에 그리기) 권한이 필요 없습니다.
  접근성 오버레이(`TYPE_ACCESSIBILITY_OVERLAY`)로 패널을 그립니다.

## 빌드 방법

가장 쉬운 방법은 **Android Studio**로 여는 것입니다.

1. Android Studio에서 이 폴더를 `Open` 합니다.
2. Gradle 동기화가 끝나면 상단의 ▶(Run)로 폰에 설치합니다.
   (폰의 개발자 옵션 → USB 디버깅 켜기 필요)

명령줄로 빌드하려면 Gradle이 설치된 상태에서:

```bash
gradle wrapper          # 최초 1회 (gradlew 생성)
./gradlew assembleDebug # app/build/outputs/apk/debug/app-debug.apk 생성
```

> 참고: 이 저장소에는 gradle-wrapper.jar 바이너리를 넣지 않았습니다.
> Android Studio로 열면 자동으로 처리되고, 명령줄이면 위 `gradle wrapper`가 만들어 줍니다.

## 사용 방법

1. 앱을 실행하고 **접근성 설정 열기**를 누릅니다.
2. 설치된 서비스 목록에서 **자동 스크롤**을 켭니다.
3. 켜지면 화면 위쪽에 조작 패널이 나타납니다.
4. 읽을 소설 앱/브라우저를 연 뒤 패널의 **▶ 시작**을 누릅니다.
5. **슬라이더**로 속도(40~700 px/s)를 조절하고, **⏸ 정지**로 멈춥니다.

### 패널 버튼

| 버튼 | 설명 |
|------|------|
| ▶ 시작 / ⏸ 정지 | 자동 스크롤 시작·정지 |
| 방향 ↑ / ↓ | 읽기 진행 방향(아래로 진행 / 위로 되돌리기) |
| 불규칙 ON/OFF | 켜면 속도가 매번 조금씩 달라져 자연스럽게 |
| ⠿ (손잡이) | 끌어서 패널 위치 이동 |

끄려면 접근성 설정에서 서비스를 다시 끕니다.

## 요구 사항

- Android 7.0 (API 24) 이상
